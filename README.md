# Hotel Frontend

Este es el frontend para el Sistema de Gestión Hotelera, diseñado con un estilo moderno e incluyendo un video de fondo en la landing page. Está construido usando:
- React
- Vite
- Tailwind CSS
- Lucide React (para los íconos)

## Requisitos previos

Debes tener instalado **Node.js** (que incluye `npm`). Si no lo tienes, descárgalo e instálalo desde [nodejs.org](https://nodejs.org/).

## Instrucciones para ejecutar

1. Abre una terminal y navega a la carpeta de este proyecto (`hotel-frontend`).
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre tu navegador en la URL que aparecerá en la consola (normalmente `http://localhost:5173`).
